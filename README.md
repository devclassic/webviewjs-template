# webviewjs 桌面应用开发模板

bun/deno + vite + webview

## 平台依赖

### Windows

[Webview2](https://developer.microsoft.com/microsoft-edge/webview2)

### Linux

```sh
# 开发依赖
sudo apt install -y \
  pkg-config \
  libwebkit2gtk-4.1-dev \
  libsoup-3.0-dev \
  libglib2.0-dev \
  libcairo2-dev \
  libpango1.0-dev \
  libatk1.0-dev \
  libgdk-pixbuf-2.0-dev \
  libgtk-3-dev \
  libxdo-dev
```
